# BEL-Gruppe: Herausnehmbarer Zahnersatz (301 0 – 384 0)

Aufstellung, Fertigstellung, gebogene Halteelemente, Sonderkunststoffe.
Quelle: [[quelle-bel-ii-2014]], S. 69–79 und 132.

## Das Grundeinheit-plus-Zahn-Prinzip
Aufstellung und Fertigstellung sind jeweils zweistufig aufgebaut: eine Grundeinheit je
Kiefer plus eine Position je Zahn.

| Schritt | Grundeinheit je Kiefer | je Zahn |
|---------|------------------------|---------|
| Aufstellung | 301 0 (Implantat: 301 8) | 302 0 Wachs-/Kunststoffbasis (Implantat: 302 8) · 303 0 Metallbasis (keine Implantatvariante) |
| Fertigstellung | 361 0 (Implantat: 361 8) | 362 0 (Implantat: 362 8) |

- 301 0 ist die Grundeinheit für die Aufstellung von Konfektionszähnen auf Wachs-,
  Kunststoff- oder Metallbasis unter Verwendung eines Mittelwertartikulators.
- 361 0 umfasst die Fertigstellung mit Kunststoff- oder Metallbasis unter Verwendung
  eines Mittelwertartikulators, einschließlich des ggf. notwendigen Abdeckens von
  Kieferteilen und/oder des Vornehmens von Radierungen.
- 302 0 / 303 0 / 362 0 je tatsächlich aufgestelltem konfektioniertem Zahn.
- 302 0 und 303 0 sind erneut abrechenbar, wenn eine weitere Bissnahme erforderlich ist.

341 0 Übertragung je Zahn — Übertragung einer auf Wachs- oder Kunststoffbasis erfolgten
Aufstellung auf eine Metallbasis. Neben 341 0 ist 303 0 für denselben
Konfektionszahn nicht abrechenbar: entweder direkt auf Metall aufstellen (303 0) oder
umsetzen (341 0).

## Gebogene Halte- und Stützvorrichtungen (380 0, 380 5, 381 0)
Das gebogene Pendant zum gegossenen Modellguss-Repertoire.

| L-Nr. | Kurztext | Umfasst |
|-------|----------|---------|
| 380 0 | Einfache gebogene Halte-/Stützvorrichtung | einarmige Klammer, Inlayklammer, Interdental-Knopfklammer, Approximalklammer, Auflage (nicht Kralle), Bonyhardklammer ohne Auflage, gebogene Lösungshilfe für Kombinationszahnersatz |
| 380 5 | Gebogene Auflage | die einfache gebogene Auflage (nicht Kralle) |
| 381 0 | Sonstige gebogene Halte- und/oder Stützvorrichtung | Doppelarmklammer (auch mit Auflage), Bonyhardklammer mit Gegenlager (auch mit Auflage), Überwurfklammer, Doppelbogenklammer mit Gegenlager (auch mit Auflage) |

Merksatz: 380 0 und 380 5 sind einfach oder einarmig, 381 0 ist mehrarmig oder mit Gegenlager.
In der KFO gilt die eigene Systematik 750 0 / 751 0; ein dort nicht benanntes
Element fällt zurück auf 380 0 bzw. 381 0 → [[bel-gruppe-kieferorthopaedie]].
Vorgefertigte Klammern sind konfektionierte Hilfsteile und nicht gesondert
berechenbar → [[bel-ii-zusatzkosten-material]].

## Sonder- und Weichkunststoff (382 1, 382 2)
| L-Nr. | Kurztext | Regel |
|-------|----------|-------|
| 382 1 | Weichkunststoff | Verarbeitung bei Herstellung/Wiederherstellung einer Prothesenbasis, eines Basisteils oder bei Herstellung eines Aufbissbehelfs. 1× je Prothese oder je Aufbissbehelf |
| 382 2 | Sonderkunststoff | wie oben, aber nur bei zahnärztlicher Indikationsstellung. 1× je Prothese oder je Aufbissbehelf |

Das KFO-Pendant ist 712 1 / 712 2 (dort: 1× je Kiefer).
Die Materialkosten laufen separat über § 2 Ziff. 4 → [[bel-ii-zusatzkosten-material]].

## Individuell gefertigte Zähne (383 0, 384 0)
| L-Nr. | Kurztext | Regel |
|-------|----------|-------|
| 383 0 | Zahn zahnfarben hergestellt | Zahn aus zahnfarbenem Kunststoff oder Komposit. Nur abrechnungsfähig, wenn aus anatomischen Gründen kein Konfektionszahn verwendbar ist. Neben 383 0 sind für denselben Zahn 302 0, 302 8, 303 0, 341 0, 362 0 und 362 8 nicht abrechenbar |
| 384 0 | Zahn zahnfarben hinterlegen | Hinterlegen eines Konfektionszahnes mit zahnfarbenem Kunststoff. Abrechenbar im OK bis einschließlich Zahn 5, im UK bis einschließlich Zahn 4 |

Abgrenzung: 383 0 ersetzt den Konfektionszahn komplett und damit auch dessen
Aufstellungs- und Fertigstellungspositionen; 384 0 ergänzt ihn nur.
