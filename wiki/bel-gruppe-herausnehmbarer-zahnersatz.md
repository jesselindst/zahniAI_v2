Nummernkreis 301 0 bis 384 0. Aufstellung, Fertigstellung, gebogene Halteelemente, Kunststoffe.

## Grundeinheit plus Zahn

Aufstellung und Fertigstellung folgen demselben Muster: eine Grundeinheit je Kiefer, dazu eine Position je Zahn.

| Vorgang | Grundeinheit je Kiefer | je Zahn |
|---|---|---|
| Aufstellung, Regelfall | 301 0 | 302 0 (Wachs-/Kunststoffbasis), 303 0 (Metallbasis) |
| Aufstellung, Implantat Nr. 36 b | 301 8 | 302 8 |
| Fertigstellung, Regelfall | 361 0 | 362 0 |
| Fertigstellung, Implantat Nr. 36 b | 361 8 | 362 8 |

301 0 ist als Grundeinheit für die Aufstellung von Konfektionszähnen auf Wachsbasis, Kunststoffbasis oder Metallbasis unter Verwendung eines Mittelwertartikulators abrechenbar (BEL II, Nr. 301 0).

361 0 ist die Grundeinheit der Fertigstellung einer Prothese mit Kunststoff- oder Metallbasis unter Verwendung eines Mittelwertartikulators, einschließlich des ggf. notwendigen Abdeckens von Kieferteilen und/oder des Vornehmens von Radierungen (BEL II, Nr. 361 0).

Die Je-Zahn-Positionen sind entsprechend der Zahl der aufgestellten konfektionierten Zähne abrechenbar. Wird eine weitere Bissnahme erforderlich, sind 302 0, 302 8 und 303 0 erneut abrechenbar (BEL II, Nr. 302 0, 302 8, 303 0).

**341 0 Übertragung je Zahn** — Übertragung einer auf einer Wachs- oder Kunststoffbasis erfolgten Aufstellung auf eine Metallbasis. Neben 341 0 ist für denselben Konfektionszahn 303 0 nicht abrechenbar (BEL II, Nr. 341 0).

Die Reihenfolge entscheidet also über die Position: direkt auf Metall aufgestellt ist 303 0, von Wachs oder Kunststoff auf Metall übertragen ist 341 0.

## Aufbissbehelfe brechen das Muster

Werden an einem Aufbissbehelf in zahnlosen Kieferabschnitten konfektionierte Zähne angebracht, sind 302 0 und 362 0 abrechenbar, nicht jedoch 301 0 oder 361 0 (BEL II, Nr. 401 0 und Nr. 402 0). Siehe [[bel-gruppe-aufbissbehelfe]].

## Gebogene Halte- und Stützvorrichtungen

| L-Nr. | Leistung | Umfasst |
|---|---|---|
| 380 0 | Einfache gebogene Halte-/Stützvorrichtung | einarmige Klammer, Inlayklammer, Interdental-Knopfklammer, Approximalklammer, Auflage (nicht Kralle), Bonyhardklammer ohne Auflage, gebogene Lösungshilfe für Kombinationszahnersatz |
| 380 5 | Gebogene Auflage | die einfache gebogene Auflage (nicht Kralle) |
| 381 0 | Sonstige gebogene Halte- und/oder Stützvorrichtung | Doppelarmklammer, Doppelarmklammer mit Auflage, Bonyhardklammer mit Gegenlager, dieselbe mit Auflage, Überwurfklammer, Doppelbogenklammer mit Gegenlager, dieselbe mit Auflage |

Die Kralle ist in beiden Listen ausdrücklich ausgenommen; sie ist ein gegossenes Element und läuft über 202 5, siehe [[bel-gruppe-modellguss]].

In der Kieferorthopädie treten 750 0 und 751 0 an die Stelle von 380 0 und 381 0. Wird dort ein Element hergestellt, das in 750 0 bzw. 751 0 nicht benannt ist, fällt es zurück auf 380 0 bzw. 381 0, siehe [[bel-gruppe-kieferorthopaedie]].

## Kunststoffe

**382 1 Weichkunststoff** — Verarbeitung bei der Herstellung oder Wiederherstellung der Basis einer Prothese, eines Basisteils einer Prothese oder bei der Herstellung eines Aufbissbehelfs. Je Prothese oder je Aufbissbehelf einmal.

**382 2 Sonderkunststoff** — Verarbeitung bei der Herstellung oder Wiederherstellung einer Prothese oder eines Aufbissbehelfs. Nur bei zahnärztlicher Indikationsstellung. Einmal je Prothese oder je Aufbissbehelf (BEL II, Nr. 382 2).

Beide Positionen vergüten den Verarbeitungsaufwand. Das Material selbst ist zusätzlich abrechenbar, siehe [[gesondert-abrechenbare-materialien-bel]].

## Individuell gefertigte Zähne

**383 0 Zahn zahnfarben hergestellt** — Herstellen eines Zahnes aus zahnfarbenem Kunststoff oder Komposit. Nur abrechnungsfähig, wenn aus anatomischen Gründen kein Konfektionszahn verwendbar ist. Neben 383 0 sind für denselben Zahn 302 0, 302 8, 303 0, 341 0, 362 0 und 362 8 nicht abrechenbar (BEL II, Nr. 383 0).

Der individuell hergestellte Zahn ersetzt also die gesamte Aufstell- und Fertigstellungskette für diesen Zahn.

**384 0 Zahn zahnfarben hinterlegt** — Hinterlegen eines Konfektionszahnes mit zahnfarbenem Kunststoff. Im Oberkiefer bis einschließlich Zahn 5, im Unterkiefer bis einschließlich Zahn 4 abrechenbar (BEL II, Nr. 384 0).

Künstliche Zähne sind gesondert abrechenbares Material, siehe [[gesondert-abrechenbare-materialien-bel]].
