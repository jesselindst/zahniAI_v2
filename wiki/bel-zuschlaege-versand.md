Vier Positionen außerhalb der Herstellungsgruppen: drei für Versand, eine für den Verarbeitungsaufwand bei Nichtedelmetall.

## Versandkosten

| L-Nr. | Anwendung |
|---|---|
| 933 0 | allgemein |
| 933 5 | Unterkieferprotrusionsschiene |
| 933 8 | Implantatversorgung nach Nr. 36 der Zahnersatz-Richtlinie |

Abgegolten werden Auslagen für Versand, wie z. B. Versand durch Laborboten je Versandgang, Versand durch Kurier je Versandgang, Versand durch Paketdienst (BEL II, Nr. 933 0, 933 5, 933 8).

**Pauschale statt Einzelnachweis.** Die Versandkosten sind pauschal abzurechnen. Zur Bestimmung der Pauschale ist das Prinzip der Wirtschaftlichkeit der Versorgung (§ 12 SGB V) zu beachten. Eine Höhe nennt das Verzeichnis nicht; sie ergibt sich aus der regionalen Preisvereinbarung, siehe [[bel-ii]].

**Nicht für Praxislabore.** 933 0, 933 5 und 933 8 können nicht für Leistungen abgerechnet werden, die in Praxislaboratorien erbracht werden.

## Verarbeitungsaufwand NEM-Legierung

**970 0** vergütet den Mehraufwand der Verarbeitung von Nichtedelmetall. Edelmetallhaltige Dentallegierungen werden dagegen als Material erstattet, siehe [[gesondert-abrechenbare-materialien-bel]] — für NEM gibt es keine Materialerstattung, sondern diese Verarbeitungsposition.

Die Erläuterung zur Abrechnung zählt abschließend auf, je welcher Position 970 0 abrechenbar ist (BEL II, Nr. 970 0):

| L-Nr. | Leistung |
|---|---|
| 024 0 | Übertragungskappe |
| 101 3 | Wurzelstiftkappe |
| 102 1 | Vollkrone/Metall |
| 102 2 | Teilkrone |
| 102 3 | Flügel für Adhäsivbrücke |
| 102 4 | Krone für vestibuläre Verblendung |
| 102 6 | Vollkrone/Metall bei Implantatversorgung |
| 102 8 | Krone für vestibuläre Verblendung bei Implantatversorgung |
| 104 0 | Angelieferte Modellation für Stiftaufbau gießen |
| 105 0 | Stiftaufbau |
| 110 0 | Brückenglied, Metall |
| 120 0 | Primärteil einer teleskopierenden Krone |
| 120 0 | Sekundärteil einer teleskopierenden Krone |
| 120 1 | Primär- oder Sekundärteil einer teleskopierenden Krone |
| 133 1 | Individuelle Verbindungsvorrichtung |

Bei 120 0 ist 970 0 ausdrücklich für Primärteil **und** Sekundärteil getrennt aufgeführt, also zweimal je teleskopierender Krone.

Die Liste umfasst ausschließlich Positionen des festsitzenden Zahnersatzes und die Übertragungskappe. Für Modellgussbasis (201 0), gegossene Klammern und die metallischen Elemente des herausnehmbaren Zahnersatzes ist 970 0 nicht vorgesehen.
