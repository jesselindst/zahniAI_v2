# BEL-Gruppe: Reparatur und Erweiterungen (801 0 – 870 0)

Instandsetzung, Unterfütterung, Basiserneuerung.
Quelle: [[quelle-bel-ii-2014]], S. 100–123 und 135.

## Das Grundeinheit-plus-Leistungseinheit-Prinzip
Instandsetzungen bestehen aus einer Grundeinheit (1× je Werkstück) plus beliebig
vielen Leistungseinheiten (LE). Es gibt vier Grundeinheiten; die richtige hängt am
Werkstück:

| Grundeinheit | Für | kombinierbar mit |
|---|---|---|
| 801 0 Grundeinheit ZE | Prothese (Kunststoff-/Metallbereich) | 802 1 – 802 7, 160 0, 164 0, 383 0, 384 0 |
| 801 8 Grundeinh. Instands. ZE/implantatgest. | implantatgestützte Prothese, nur Nr. 36 b | nur 802 1, 802 2, 802 3, 802 4 |
| 861 0 Grundeinheit/Instands. KFO oder Aufbissbehelf | KFO-/FKO-Gerät oder Aufbissbehelf | 862 0, 863 0, 802 1, 802 2, 802 3, 802 4 |
| 850 0 Grundeinheit Instandsetzung/Erweiterung UKPS | Unterkieferprotrusionsschiene | 510 0, 511 0, 520 0, 521 0, 851 1 – 851 4 → [[bel-ii-ukps]] |

Jede Grundeinheit ist einmal je Prothese, Gerät, Aufbissbehelf oder UKPS abrechenbar.

## Leistungseinheiten Zahnersatz (802 x)
| L-Nr. | Kurztext | Menge / Inhalt |
|-------|----------|----------------|
| 802 1 | LE Sprung | Sprung im Kunststoff/Metall beseitigen, auch bei KFO-Geräten. LE je zusammenhängende Sprunglinie |
| 802 2 | LE Bruch | Bruch im Kunststoff/Metall, auch Drahtbruch KFO. LE je Bruch |
| 802 3 | LE Einarbeiten Zahn | Wiederbefestigung, Erweiterung Zahn, auch Erneuerung, Herauslösen eines Konfektionszahnes. LE je Zahn |
| 802 4 | LE Basisteil Kunststoff | siehe Sonderregeln unten |
| 802 5 | LE Halte- und/oder Stützvorrichtung einarbeiten | gebogen oder gegossen, auch bei Verwendung einer vorhandenen Vorrichtung. Je Halte-/Stützvorrichtung |
| 802 6 | LE Rückenschutzplatte einarbeiten | Einarbeitung einer gegossenen Rückenschutzplatte nach 208 1 i. V. m. Erweiterung/Erneuerung eines Zahnes |
| 802 7 | LE Kunststoffsattel | Kunststoffsattel lösen und wieder befestigen. 1× je Sattel |

### Sonderregeln zu 802 4 (LE Basisteil Kunststoff)
- Nur berechenbar, wenn an derselben Stelle keine andere Leistung erbracht wird.
- Das Verkleiden der Retention ist Bestandteil von 802 3 bzw. 802 4 und an gleicher
  Stelle nicht als eigenständige Leistung abrechenbar.
- Kann als Gegenlager einer einarmigen Klammer abgerechnet werden.
- Nicht abrechenbar bei einer Erweiterung nach 802 3 für die Neugestaltung eines
  bukkalen Schildes.
- Für das Auffüllen einer Sekundärkrone nur dann, wenn eine Abformung zur
  Basiserweiterung erfolgt ist. Eine ggf. notwendige Unterfütterung ist zusätzlich
  nach 808 0, 808 8, 809 0, 809 8, 810 0, 810 8 abrechenbar.

## Unterfütterung und Basiserneuerung (808 x – 810 x, 864 0)
| L-Nr. | Kurztext | Menge |
|-------|----------|-------|
| 808 0 | Teilunterfütterung einer Basis | 1× je Prothese oder KFO-/FKO-Basis |
| 808 5 | Teilunterfütterung einer Basis UKPS | 1× je Basis → [[bel-ii-ukps]] |
| 808 8 | Teilunterfütterung/implantatgest. | 1× je Prothese, Nr. 36 b |
| 809 0 | Vollständige Unterfütterung | 1× je Prothese und KFO-Basis, bei bimaxillärem Gerät je Kiefer. Umfasst auch Unterfütterung mit funktioneller Randgestaltung |
| 809 8 | Vollständige Unterfütterung/implantatgestützte Basis | 1× je Prothese, Nr. 36 b |
| 810 0 | Prothesenbasis erneuern | vollständige Entfernung und Erneuerung der Kunststoffbasis bei Erhaltung des Zahnkranzes. 1× je Prothese |
| 810 8 | Prothesenbasis erneuern/Implantatversorgung | 1× je Prothese, Nr. 36 b |
| 864 0 | KFO-Basis erneuern | vollständige Entfernung und Erneuerung der Kunststoffbasis bei Erhaltung der herausgelösten Halte-, Dehn- und Regulierungselemente. 1× je KFO-Basis |

Alle enthalten gegebenenfalls die Sicherung von vorhandenen Verbindungselementen.

### Zwei Regeln, die für alle diese Positionen gelten
1. Unterfütterung und Basiserneuerung sind keine Instandsetzung.
   808 0, 809 0, 810 0 sind ausdrücklich keine Instandsetzung i. S. v. 801 0, 802 1 – 802 7 (bei
   808 0 und 809 0 zusätzlich: 861 0, 862 0, 863 0). Ebenso 864 0 gegenüber 861 0, 862 0, 863 0
   und 808 8 / 809 8 / 810 8 gegenüber 801 8, 802 1 – 802 7.
   Es ist also keine Grundeinheit anzusetzen, wenn ausschließlich unterfüttert oder die Basis
   erneuert wird.
2. Bisslagefixierung: Fixator ja, Artikulator nein.
   Für die Fixierung der Bisslage mit einem zweiten Modell und dem Einstellen in einen
   Fixator sind 001 0 + 011 2 abrechenbar, 012 0 (Mittelwertartikulator) nicht.
   Gilt für 808 0, 809 0, 810 0, 864 0. Implantat-Varianten: 001 8 + 011 2, nicht 012 8.
   UKPS: 001 5 + 011 5, nicht 012 5.
