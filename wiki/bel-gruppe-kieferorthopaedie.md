# BEL-Gruppe: Kieferorthopädie (701 0 – 751 0)

Basen, Schrauben, Bögen, Federn, Verbindungselemente, gebogene Halteelemente.
Quelle: [[quelle-bel-ii-2014]], S. 86–99 und 134.

## Basen (701 0 – 705 0)
| L-Nr. | Kurztext | Inhalt / Regel |
|-------|----------|----------------|
| 701 0 | Basis für Einzelkiefergerät | aus **Kunststoff oder Metall**, für verschiedene KFO-Apparaturen (z. B. Crozat-Gerät), **einschließlich Radieren nach System und Abdecken von Kieferteilen** |
| 702 0 | Basis bimaxilläres Gerät | aus **Kunststoff**, auch elastisch, inkl. Radieren/Abdecken. Bei **horizontaler Teilung** statt 702 0 **zweimal 701 0**. Auch für einen **individuell gefertigten Positioner** abrechenbar |
| 703 0 | Schiefe Ebene | Basis aus Kunststoff + Herstellung einer schiefen Ebene. ⚠️ Wird die schiefe Ebene **i. V. m. einer Basis nach 701 0** gefertigt, ist sie **nicht nach 703 0, sondern nach 710 0** abzurechnen |
| 704 0 | Vorhofplatte | individuell gefertigte **Mundvorhofplatte** |
| 705 0 | Kinnkappe | individuell gefertigt, für **extraorale Verankerung**, **einschließlich Kinnmodell und Befestigungshaken**. Auch für die Versorgung von **Traumata (Kieferbruch)** abrechenbar |

## Aufbisse, Abschirmung, Kunststoffe (710 0 – 712 2)
| L-Nr. | Kurztext | Regel |
|-------|----------|-------|
| 710 0 | Aufbiss | aus Hart- und/oder Weichkunststoff, **auch als Vor- oder Rückbiss**. **1× je Kieferhälfte oder Frontzahngebiet** |
| 711 0 | Abschirmelement | z. B. **Zungengitter, Kunststoffschild, Kunststoffpelotte**. **1× je Kieferhälfte oder Frontzahngebiet** |
| 712 1 | Weichkunststoff (KFO) | bei Herstellung/Wiederherstellung eines **Positioners**, von **Aufbissen** oder **Abschirmelementen**. **1× je Kiefer**. ⚠️ Bei Verwendung **elastischer Fertigteile nicht neben 710 0** abrechenbar |
| 712 2 | Sonderkunststoff (KFO) | bei Herstellung/Wiederherstellung eines KFO-/FKO-Gerätes oder von Aufbissen/Abschirmelementen. **Nur bei zahnärztlicher Indikationsstellung.** **1× je Kiefer** |

## Schrauben und Basistrennung (720 0 – 722 0)
| L-Nr. | Kurztext | Regel |
|-------|----------|-------|
| 720 0 | Schraube einarbeiten | **Standard**schraube (z. B. Dehnschraube) in eine Basis |
| 721 0 | Spezialschraube einarbeiten | Als Spezial-Schrauben gelten z. B.: Schrauben, deren Konstruktion **ausschließlich Einzelzahnbewegung** zulässt · Schrauben zur **gezielten Sektorenbewegung** · Schrauben für **asymmetrische Bewegungen** · Schrauben zur **Metallverbindung** · **reziproke** Druck- und Zugschraube · **sagittale** Druck-/Zugschraube · **transversale** Zugschraube |
| 722 0 | Trennen einer Basis | umfasst: Trennen einer Basis · Trennen kompliziert · Trennen **ohne Schraube** · Trennen nach Instandsetzung oder Unterfütterung. **1× je Trennung oder je Schraube nach 720 0/721 0** |

Die Schrauben selbst sind **Konfektionsfertigteile** und damit gesondert abrechenbar
→ [[bel-ii-zusatzkosten-material]].

## Bögen und Federn (730 0 – 734 0)
| L-Nr. | Kurztext | Abgrenzung |
|-------|----------|-----------|
| 730 0 | Labialbogen | intramaxillär, **mit zwei Schlaufen** |
| 731 0 | Labialbogen modifiziert | intramaxillär, **mit mehr als zwei Schlaufen** |
| 732 0 | Labialbogen intermaxillär | Bogen **mit Beziehung zum Gegenkiefer** |
| 733 0 | Feder, offen | **alle offenen Federn mit einer Retention** — z. B. Protrusionsfeder, Interdentalfeder, Feder gekreuzt, auch **aktiver Dorn oder Sporn** |
| 734 0 | Feder, geschlossen | **alle geschlossenen Federn mit zwei Retentionen** — z. B. Protrusionsbogen, Paddelfeder, auch **Schlinge, Schlaufe** |

Merkmal für offen/geschlossen ist die **Zahl der Retentionen** (1 vs. 2), nicht die Form.
Vorgefertigte Labialbögen sind **konfektionierte Hilfsteile** und nicht gesondert berechenbar
→ [[bel-ii-zusatzkosten-material]].

## Verbindungs-, Führungs- und Verankerungselemente (740 0 – 744 0)
| L-Nr. | Kurztext | Umfasst / Regel |
|-------|----------|-----------------|
| 740 0 | Verbindungselement/intramaxillär | z. B. **Coffin-Feder, Transversalbügel, orthodontischer Lingual- oder Palatinalbogen, Verbindung zwischen Basisteilen** |
| 741 0 | Verbindungselemente/intermaxillär | z. B. **U-Bügel, Federbügel, Doppelplattensteg**. **1× je Paar.** Die **Erneuerung** eines Elements → **863 0** |
| 742 0 | Verankerungselement | **Ankerband oder Ankerkappe, individuell gefertigt** |
| 743 0 | Einzelelement einarbeiten | z. B. **Schloss, Röhrchen, Lückenhalter, Lückendehner** |
| 744 0 | Metallverbindung (KFO) | **je Verbindungsstelle**, **auch bei Wiederherstellung und/oder Erweiterung** |

## Gebogene Halte-/Abstützelemente (750 0, 751 0)
| L-Nr. | Kurztext | Umfasst |
|-------|----------|---------|
| 750 0 | Einarmiges H-/A-Element | **Halte**element gebogen: Tropfen-, Ösen-, Dreiecksklammer, Pfeil-, **Knopfanker**, Crozat-Haltesporn — oder **Abstütz**element gebogen: Dorn, Auflage, Steg |
| 751 0 | Mehrarmiges H-/A-Element | mehrarmiges Halteelement gebogen: **Adams-, Pfeil-, Voß-, Crozatklammer** |

⚠️ **Auffangregel:** Wird ein Element hergestellt, das in der Erläuterung **nicht benannt**
ist, ist es nach **380 0** (einarmig) bzw. **381 0** (mehrarmig) abzurechnen — nicht nach
750 0/751 0. → [[bel-gruppe-herausnehmbarer-zahnersatz]]

## KFO-spezifische Vorbereitung und Reparatur
- Modelle/Planung: **011 1** (Modellpaar trimmen, nur KFO) · **013 0** (Modellpaar sockeln,
  KFO-Dokumentationsmodelle) · **003 0 + 005 4** (Set-up) · **020 2** (Basis für
  Konstruktionsbiss bei bimaxillären Geräten) → [[bel-gruppe-arbeitsvorbereitung]]
- Instandsetzung: **861 0, 862 0, 863 0, 864 0, 870 0** (+ 802 1–802 4)
  → [[bel-gruppe-reparatur-erweiterung]]
- Retainer als semipermanente Metallschiene: **404 0** → [[bel-gruppe-aufbissbehelfe]]
