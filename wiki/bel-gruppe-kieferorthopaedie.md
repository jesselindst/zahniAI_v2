Nummernkreis 701 0 bis 751 0. Die kieferorthopädische Behandlung ist einer der vier Anwendungsbereiche des BEL (BEL II, Anlage 1, § 1 Ziffer 1).

## Basen

**701 0 Basis für Einzelkiefergerät** — aus Kunststoff oder Metall für verschiedene Arten kieferorthopädischer Apparaturen (z. B. Crozat-Gerät), einschließlich Radieren nach System und Abdecken von Kieferteilen.

**702 0 Basis bimaxilläres Gerät** — aus Kunststoff, auch elastisch, einschließlich Radieren nach System und Abdecken von Kieferteilen. Bei horizontaler Teilung ist statt 702 0 zweimal 701 0 abrechenbar. Auch für einen individuell gefertigten Positioner abrechenbar (BEL II, Nr. 702 0).

**703 0 Schiefe Ebene** — Basis aus Kunststoff und Herstellung einer schiefen Ebene. Wird eine schiefe Ebene in Verbindung mit einer Basis für Einzelkiefergerät nach 701 0 gefertigt, so ist sie nicht nach 703 0, sondern nach 710 0 abrechenbar (BEL II, Nr. 703 0).

703 0 enthält die Basis bereits. Kommt die schiefe Ebene zu einer eigenständigen 701 0 hinzu, wäre die Basis doppelt bezahlt — deshalb der Wechsel auf 710 0.

## Weitere Geräte

| L-Nr. | Leistung | Anmerkung |
|---|---|---|
| 704 0 | Vorhofplatte | individuell gefertigte Mundvorhofplatte |
| 705 0 | Kinnkappe | individuell gefertigt für extraorale Verankerung, einschließlich Kinnmodell und Befestigungshaken; auch für die Versorgung von Traumata (Kieferbruch) abrechenbar |
| 710 0 | Aufbiss | aus Hart- und/oder Weichkunststoff, auch als Vor- oder Rückbiss; einmal je Kieferhälfte oder Frontzahngebiet |
| 711 0 | Abschirmelement | Zungengitter, Kunststoffschild, Kunststoffpelotte; einmal je Kieferhälfte oder Frontzahngebiet |

705 0 ist bemerkenswert, weil sie den Rahmen der KFO verlässt: Kieferbruchbehandlungen werden sonst nach tatsächlichem Aufwand abgerechnet, siehe [[bel-ii]].

## Kunststoffe

**712 1 Weichkunststoff (KFO)** — Verarbeitung bei der Herstellung oder Wiederherstellung eines Positioners, von Aufbissen oder von Abschirmelementen. Je Kiefer einmal. Bei der Verwendung von elastischen Fertigteilen neben 710 0 nicht abrechenbar (BEL II, Nr. 712 1).

**712 2 Sonderkunststoff (KFO)** — Verarbeitung bei der Herstellung oder Wiederherstellung eines KFO-Gerätes, FKO-Gerätes oder von Aufbissen und Abschirmelementen. Nur bei zahnärztlicher Indikationsstellung. Einmal je Kiefer (BEL II, Nr. 712 2).

## Schrauben und Trennung

**720 0 Schraube einarbeiten** — Einarbeiten einer Standardschraube (z. B. Dehnschraube) in eine Basis.

**721 0 Spezial-Schraube einarbeiten** — als Spezial-Schrauben gelten z. B. Schrauben, deren Konstruktion ausschließlich Einzelzahnbewegung zulässt; Schrauben zur gezielten Sektorenbewegung; Schrauben für asymmetrische Bewegungen; Schrauben zur Metallverbindung; reziproke Druck- und Zugschraube; sagittale Druck- oder Zugschraube; transversale Zugschraube (BEL II, Nr. 721 0).

**722 0 Trennen einer Basis** — Trennen einer Basis, auch kompliziert, ohne Schraube oder nach Instandsetzung oder Unterfütterung. Je Trennung oder je Schraube nach 720 0 und 721 0 einmal abrechenbar (BEL II, Nr. 722 0).

Die Schrauben selbst sind Konfektionsfertigteile und gesondert abrechenbar, siehe [[gesondert-abrechenbare-materialien-bel]].

## Bögen und Federn

| L-Nr. | Leistung | Definition |
|---|---|---|
| 730 0 | Labialbogen | intramaxillär, mit zwei Schlaufen |
| 731 0 | Labialbogen modifiziert | intramaxillär, mit mehr als zwei Schlaufen |
| 732 0 | Labialbogen intermaxillär | mit Beziehung zum Gegenkiefer |
| 733 0 | Feder, offen | alle offenen Federn mit einer Retention, z. B. Protrusionsfeder, Interdentalfeder, Feder gekreuzt, auch aktiver Dorn oder Sporn |
| 734 0 | Feder, geschlossen | alle geschlossenen Federn mit zwei Retentionen, z. B. Protrusionsbogen, Paddelfeder, auch Schlinge, Schlaufe |

Die Zahl der Schlaufen entscheidet zwischen 730 0 und 731 0, die Zahl der Retentionen zwischen 733 0 und 734 0.

## Verbindungs- und Verankerungselemente

**740 0 Verbindungselement intramaxillär** — Coffin-Feder, Transversalbügel, orthodontischer Lingual- oder Palatinalbogen, Verbindung zwischen Basisteilen.

**741 0 Verbindungs- oder Führungselemente intermaxillär** — U-Bügel, Federbügel, Doppelplattensteg. Je Paar einmal abrechenbar. Die Erneuerung eines Elementes ist nach 863 0 abrechenbar (BEL II, Nr. 741 0).

**742 0 Verankerungselement** — Ankerband oder Ankerkappe, individuell gefertigt.

**743 0 Einzelelement einarbeiten** — z. B. Schloss, Röhrchen, Lückenhalter oder Lückendehner.

**744 0 Metallverbindung (KFO)** — je Verbindungsstelle, auch bei Wiederherstellung und/oder Erweiterung.

## Halte- und Abstützelemente

**750 0 Einarmiges Halte-/Abstützelement, je Zahn** — einarmiges Halteelement gebogen (Tropfen-, Ösen-, Dreiecksklammer, Pfeil-, Knopfanker, Crozat-Haltesporn) oder Abstützelement gebogen (Dorn, Auflage, Steg).

**751 0 Mehrarmiges Halte-/Abstützelement, je Zahn** — mehrarmiges Halteelement, gebogen (Adams-, Pfeil-, Voß-, Crozatklammer).

Wird ein Element hergestellt, das in der jeweiligen Erläuterung nicht benannt ist, ist es nach 380 0 (einarmig) beziehungsweise 381 0 (mehrarmig) abzurechnen (BEL II, Nr. 750 0 und Nr. 751 0). Die KFO-Positionen sind also abschließende Listen mit definiertem Rückfall auf die Positionen des herausnehmbaren Zahnersatzes, siehe [[bel-gruppe-herausnehmbarer-zahnersatz]].

## Modelle und Planung

003 0 (Set-up je Segment) und 005 4 (Set-up-Modell für KFO) sind in Verbindung mit KFO-Planungen und -Leistungen abrechenbar. 011 1 (Modellpaar trimmen) ist in Verbindung mit KFO-Leistungen abrechenbar, 013 0 (Modellpaar sockeln) für kieferorthopädische Dokumentationsmodelle. 020 2 (Basis für Konstruktionsbiss) und 011 2 (Fixator) gelten für Geräte mit bimaxillärer Beziehung. Siehe [[bel-gruppe-arbeitsvorbereitung]].

## Instandsetzung

Die Instandsetzung von KFO- und FKO-Geräten läuft über die Grundeinheit 861 0 mit den Leistungseinheiten 862 0, 863 0, 802 1–802 4; die vollständige Basiserneuerung über 864 0, die Remontage über 870 0. Siehe [[bel-gruppe-reparatur-erweiterung]].
