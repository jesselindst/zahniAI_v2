# BEL II – Ausschluss- und Bedingungsregeln (Querschnitt)

Alle „nicht nebeneinander / nicht abrechenbar / nur wenn"-Regeln des Verzeichnisteils an
einer Stelle. **Prüfliste vor Ausgabe jedes BEL-KVs.**
Quellen: [[quelle-bel-ii-2014]], Verzeichnisteil S. 8–127 ·
[[quelle-aenderungsvereinbarung-bel-ii-2023]] (002 3 / 005 1/2/3).

> Grundregel: Positionen sind **kompatibel und nach Ist-Menge** abrechenbar
> ([[bel-ii-grundlagen]]). Alles hier Gelistete ist die **benannte Ausnahme**.

## B. Grundeinheit vs. Unterfütterung / Basiserneuerung
Unterfütterung und Basiserneuerung sind **keine Instandsetzung** → **keine Grundeinheit**
ansetzen, wenn nur unterfüttert / die Basis erneuert wird.

| Position | ist keine Instandsetzung i. S. v. |
|---|---|
| **808 0**, **809 0** | 801 0, 802 1–802 7, **861 0, 862 0, 863 0** |
| **810 0** | 801 0, 802 1–802 7 |
| **864 0** | 861 0, 862 0, 863 0 |
| **808 8**, **809 8**, **810 8** | 801 8, 802 1–802 7 |

## C. Bisslagefixierung bei Unterfütterung / Basiserneuerung
Zweites Modell + Fixator **ja**, Mittelwertartikulator **nein**:

| Fall | abrechenbar | NICHT abrechenbar |
|---|---|---|
| 808 0 / 809 0 / 810 0 / 864 0 | **001 0 + 011 2** | **012 0** |
| 808 8 / 809 8 / 810 8 | **001 8 + 011 2** | **012 8** |
| 808 5 (UKPS) | **001 5 + 011 5** | **012 5** |

## D. Mittelwertartikulator (012 0 / 012 5 / 012 8) — wann nicht
- **Nicht**, wenn der Zahnersatz / das KFO-Gerät keine Berücksichtigung der Lateral- und
  Protrusionsbewegung erfordert — genannte Beispiele: **032 0, 104 0, 808 0** (bei 012 8:
  **808 8**).
- **Nicht**, wenn die Montage **unter Anwendung von Systemteilen** (z. B. Gesichtsbogen)
  erfolgt. Gilt für 012 0, 012 5 und 012 8.
- Nur, wenn die Modelle die **gesamten Kieferverhältnisse** wiedergeben.

## I. Materialseitige Ausschlüsse
- **Lote**: grundsätzlich nicht gesondert abrechenbar; **Ausnahme 807 0 → 75 %**.
- **Vorgefertigte Klammern, Labialbögen etc.** sind konfektionierte **Hilfsteile** und mit der
  Leistungsvergütung abgegolten — **keine** Konfektionsfertigteile.
- **970 0 (NEM)** nur für die abschließend genannten Positionen →
  [[bel-gruppe-zuschlaege-versand]].
