# Funktionsschiene (CMD) — Versorgungsform-Entscheidung

Aufbissschiene mit instrumenteller FAL-Begleitung (höhere Komplexität als einfache adjustierte Aufbissschiene).

| Versorgungsform | Wann? |
|---|---|
| `Privatleistung/` | IMMER (FAL-Aufwand → komplett-privat) |

**Abgrenzung zu `Aufbissschiene/`**: Einfache adjustierte Aufbissschiene ohne FAL = Regelversorgung. Mit FAL/CMD-Geräteeinsatz wandert die Schiene komplett in Privatleistung.
