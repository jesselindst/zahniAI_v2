# Schienen — Übersicht

Aufbiss-, Schnarcher-, TAP-, Bleaching-, Sport-, Retainer- und Funktionsschienen.

## Wann diese Hauptkategorie?

Im Konfigurator: `supplyCategory = 'splint'` (SplintConfig.tsx).

## Wichtige Klassifizierungs-Regel: Aufbissschiene verfahrensoffen

**BEL 401 0 / 402 0 ist verfahrensoffen** — Tiefziehen, CAD-CAM gefräst und 3D-gedruckt sind ALLE GKV-fähig (Regelversorgung). Voraussetzung: Indikation CMD/Bruxismus/Myoarthropathien.

**ACHTUNG REGIONAL**: In manchem KZV-Bereich (z.B. Bayern) wird digitale Herstellung NICHT als GKV anerkannt → komplett-privat. Vor Abrechnung KZV-Regelung prüfen.

**Flankierende Leistungen IMMER privat**:
- Digitale Abformung (GOZ 0065)
- Funktionsanalyse / -therapie (GOZ 8000 ff.)
- Gesichtsbogen
