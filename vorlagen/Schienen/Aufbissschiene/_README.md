# Aufbissschiene — Versorgungsform-Entscheidung

Schiene zur Therapie von CMD, Bruxismus, Myoarthropathien, Fehlgewohnheiten.

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `Regelversorgung/` | CMD/Bruxismus-Indikation, PMMA-hart, adjustiert (Tiefziehen, CAD-CAM oder 3D-gedruckt) |
| `gleichartig/` | Höherwertige Materialien/Designs (PMMA-weich, Hart-Weich-Kombi, Michigan) |
| `Privatleistung/` | Komplett-privat mit FAL-Aufwand |

## Klassifizierungs-Regel: BEL 401 0/402 0 ist verfahrensoffen

**Tiefziehen, CAD-CAM gefräst und 3D-gedruckt sind ALLE GKV-fähig** (Regelversorgung):
- BEL 401 0 = Aufbissschiene Vollabdeckung
- BEL 402 0 = Frontzahnschiene
- Es gibt keine Vorgabe zur Herstellungsmethode

## ⚠️ Achtung: Regionale Unterschiede

In manchen KZV-Bereichen (z.B. **Bayern**) wird digitale Herstellung NICHT als GKV anerkannt → Patient zahlt komplett privat. **Vor der Abrechnung KZV-Regelung prüfen!**

In den meisten anderen KZV-Bereichen sind ALLE drei Verfahren GKV-fähig (BEMA K1/K2 + BEL 401 0).

## KZV-Übermittlung bei digitaler Herstellung

Bei CAD-CAM oder 3D-Druck: interne KZV-Mitteilung erforderlich, dass die Schiene mit vorhandenen Modellen hergestellt wurde. BEL 001 0 (Modell aus Gips) entfällt bei digitaler Herstellung.

## Flankierende Leistungen IMMER privat

- Digitale Abformung (GOZ 0065)
- Funktionsanalyse / -therapie (GOZ 8000 ff.)
- Gesichtsbogen
- CMD-Diagnostik mit Geräteeinsatz

→ Komplett-Privat-Schienen mit FAL-Aufwand wandern in `Privatleistung/`.

## Häufigkeit

GKV zahlt typisch 1 Schiene pro Jahr.

## Entscheidungsbaum

1. **Komplett-Privatwunsch (PKV oder GKV-Patient mit umfassendem FAL-Aufwand)?** → `Privatleistung/`
2. **GKV mit Indikation CMD/Bruxismus**:
   - **PMMA-weich, Hart-Weich-Kombi, Michigan?** → `gleichartig/`
   - **PMMA-hart, adjustiert (egal welches Verfahren)?** → `Regelversorgung/`
3. **In Bayern (oder anderen KZV-Bereichen ohne Digital-Anerkennung)** + digitale Herstellung gewünscht → `Privatleistung/`
