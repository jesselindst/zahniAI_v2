## Verfahrens-Wahl

- **Tiefziehen**: klassisch, kein digitaler Aufwand
- **CAD-CAM**: gefräst aus Vollblock, höhere Präzision
- **3D-Druck**: lichthärtender Druckkunststoff, schnell
- **Frontzahnschiene**: nur Frontzahn-Bereich (kleinerer Umfang als Vollabdeckung)
