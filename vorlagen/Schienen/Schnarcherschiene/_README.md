# Schnarcherschiene (UPS) — Versorgungsform-Entscheidung

Unterkieferprotrusionsschiene zur Behandlung von Schnarchen oder Schlafapnoe.

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `Regelversorgung/` | Diagnostiz. obstruktive Schlafapnoe (leicht-mittelgradig), CPAP nicht erfolgreich |
| `Privatleistung/` | Einfaches habituelles Schnarchen ohne Apnoe |

## Klassifizierungs-Regel

**Seit 1.1.2022 GKV-Leistung** (G-BA-Beschluss). Voraussetzungen für Regelversorgung:
- Diagnose obstruktive Schlafapnoe (Schlaflabor)
- Leichte bis mittelgradige Ausprägung
- CPAP/Überdrucktherapie nicht erfolgreich oder nicht zumutbar

**Bei einfachem Schnarchen ohne Apnoe** → keine GKV-Leistung → `Privatleistung/`.

## Konstruktion

- `Einteilig` — eine Schiene OK+UK
- `Zweiteilig_Protrusion` — zwei Teile mit einstellbarer Protrusion (mm-genau)
