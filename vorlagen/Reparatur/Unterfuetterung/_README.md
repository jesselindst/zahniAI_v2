# Unterfuetterung — Versorgungsform-Entscheidung

Spaltbildung Prothese-Schleimhaut bei Atrophie / Lockerung der Prothese.

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `Regelversorgung/` | An GKV-Prothese, Standard-Materialien |
| `Privatleistung/` | An Privat-Prothese ODER Weichbleibend (z.B. nach Implantation) |

## Material × Scope ist abrechnungsrelevant

| Material | Eigenschaft |
|---|---|
| **Heisspolymerisation** | Dauerhaft, langlebig — höchster Aufwand |
| **Kaltpolymerisation** | Standard-Verfahren — mittlerer Aufwand |
| **Weichbleibend** | Bei sensibler Schleimhaut, postoperativ |

| Scope | Bedeutung |
|---|---|
| `Vollstaendig` | Gesamte Prothesenbasis |
| `Partiell` | Nur ein Bereich (z.B. Sattel) |

→ jede Material × Scope Kombi hat eigene BEB-Position → eigene Vorlage.
