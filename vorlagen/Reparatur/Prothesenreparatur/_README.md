# Prothesenreparatur — Versorgungsform-Entscheidung

Bruch, Riss oder Sprung der Prothesenbasis bzw. eines Zahns.

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `Regelversorgung/` | Reparatur an GKV-Regelversorgung-Prothese |
| `Privatleistung/` | Reparatur an Privat-/PKV-Prothese |

## Schadens-Typ ist abrechnungsrelevant

- `Basisbruch.md` — Prothesenbasis-Bruch (komplette Bruchstelle)
- `Zahnbruch.md` — einzelner Zahn aus Prothese gebrochen
- `Riss-Sprung.md` — Riss/Sprung ohne komplette Trennung
