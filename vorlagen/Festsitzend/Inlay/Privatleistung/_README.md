## Material-Wahl

- **Frontzahn-Approximalbereich**: LiSi (höchste Ästhetik)
- **Seitenzahn**: Gold gegossen (Langzeitstabilität) oder LiSi
- **Materialallergien**: Zirkon
- **Kostengünstig**: Komposit
