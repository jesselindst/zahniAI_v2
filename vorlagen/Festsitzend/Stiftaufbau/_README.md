# Stiftaufbau — Versorgungsform-Entscheidung

Vorbereitung wurzelbehandelter Zahn vor Überkronung — gegossen oder konfektionierter Stift.

## Versorgungsform-Tabelle

| Versorgungsform | Material |
|---|---|
| `Regelversorgung/` | NEM oder EM, gegossen (BEL) |
| `gleichartig/` | Glasfaser (GOZ 2195) |
| `Privatleistung/` | Titan, Zirkon, Carbon |

## Klassifizierungs-Regel Glasfaserstift

**Glasfaserstift = gleichartig**, NICHT Privatleistung. Begründung: GOZ 2195 ("Vorbereitung eines zerstörten Zahnes durch Schraubenaufbau oder Glasfaserstift o. Ä.") ist Mehrleistung über BEB-Anteil. Da metallfreier Stift kein BEL-Pendant hat, wird Standardversorgung gleichartig.

## Entscheidungsbaum

1. **PKV oder Privatwunsch?** → `Privatleistung/`
2. **GKV mit HKP**:
   - **NEM/EM gegossen** → `Regelversorgung/`
   - **Glasfaser** → `gleichartig/`
   - **Titan, Zirkon, Carbon** → `Privatleistung/`
