# Teleskopkrone — Versorgungsform-Entscheidung

Pfeilerkrone als Teil einer kombinierten Versorgung (Modellguss/Cover Denture mit Teleskop-Verankerung).

**Wichtig**: Teleskopkronen werden im Kombi mit der Prothese abgerechnet (siehe `Herausnehmbar/Kombinationsarbeit/`). Diese Vorlagen-Sammlung dokumentiert die Teleskop-Anteile separat — der Agent kombiniert mit der Prothesen-Vorlage.

## Versorgungsform-Tabelle

| Versorgungsform | Material/Verfahren |
|---|---|
| `Regelversorgung/` | NEM-Primär + NEM-Sekundär (BEL-Standard) |
| `gleichartig/` | Premium-Material (Zirkon, LiSi, Galvano) — auch CAD-CAM-gefräste Primärteile |
| `Privatleistung/` | beliebig (PKV oder Privatwunsch) |

**Keine andersartig-Klassifikation**: Teleskopkrone bleibt im selben ZE-Typ. Material-Wechsel = gleichartig.

## Entscheidungsbaum

1. **PKV oder Privatwunsch?** → `Privatleistung/`
2. **GKV-Patient, NEM-Primär+Sekundär?** → `Regelversorgung/`
3. **GKV-Patient, Premium (Zirkon, Galvano, LiSi)?** → `gleichartig/`

## Klassifizierungs-Regel: Zirkon-Primärteile

**WICHTIG (BEL II 2014)**: Zirkon-Primärteleskope sind CAD-CAM gefräst → IMMER **gleichartig**, NICHT andersartig. Patient erhält Festzuschuss der Regelversorgung; Mehrkosten privat.

## Teleskop-Teile

- `_komplett` = Primär + Sekundär in einer Vorlage
- `_primaer` = nur Primärteleskop
- `_sekundaer` = nur Sekundärteleskop (z.B. Galvano-Sekundär)
