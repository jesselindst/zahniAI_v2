# Einzelkrone Regelversorgung — Permutations-Auswahl

NEM-Krone als BEL-Standard nach Befund 1.x.

## Files in diesem Ordner

| File | Wann? |
|---|---|
| `NEM_vestibulaer.md` | Position innerhalb VG: OK 15-25 oder UK 34-44, vestibulär kunststoffverblendet |
| `NEM_unverblendet.md` | Position außerhalb VG: OK 16-18 oder UK 35-38, unverblendete Vollgusskrone |

## Verblendgrenzen GKV (kritisch)

Innerhalb der Verblendgrenzen ist Verblendung Festzuschuss-fähig. Außerhalb wäre Verblendung eine Mehrleistung → wechselt zu `gleichartig/`.

| Bereich | Zähne | Vorlage |
|---|---|---|
| OK Frontzahn + Praemolar | 15, 14, 13, 12, 11, 21, 22, 23, 24, 25 | `NEM_vestibulaer.md` |
| UK Frontzahn + Praemolar 4 | 34, 33, 32, 31, 41, 42, 43, 44 | `NEM_vestibulaer.md` |
| OK Molar | 16, 17, 18, 26, 27, 28 | `NEM_unverblendet.md` |
| UK Praemolar 5 + Molar | 35, 36, 37, 38, 45, 46, 47, 48 | `NEM_unverblendet.md` |
