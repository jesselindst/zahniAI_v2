# Einzelkrone — Versorgungsform-Entscheidung

Einzelne Krone auf einem präparierten Zahn (oder Implantat).

## Versorgungsform-Tabelle

| Versorgungsform | Material/Verfahren | Verblendung |
|---|---|---|
| `Regelversorgung/` | NEM-Gerüst (BEL) | vestibulär (innerhalb VG) ODER unverblendet (Molar) |
| `gleichartig/` | Premium-Material (Zirkon, LiSi, EM, VMK, Galvano) ODER CAD-CAM gefräst (jedes Material) | beliebig |
| `Privatleistung/` | beliebig | beliebig |
| ~~`andersartig/`~~ | — | — (es gibt keine "andersartige Krone" — Kronentyp-Wechsel = neue Versorgung) |

## Entscheidungsbaum

1. **PKV-Patient ODER GKV-Wunsch komplett-privat?** → `Privatleistung/`
2. **GKV-Patient mit HKP**:
   - **CAD-CAM gefräste Krone?** → `gleichartig/` (BEL II 2014: gefräste Versorgungen sind IMMER gleichartig)
   - **Zirkon, LiSi, Galvano, EM, VMK?** → `gleichartig/`
   - **NEM-Gerüst, vestibulär verblendet, Position innerhalb VG (15-25 / 34-44)?** → `Regelversorgung/NEM_vestibulaer.md`
   - **NEM-Gerüst, unverblendet, Molar (außerhalb VG)?** → `Regelversorgung/NEM_unverblendet.md`
   - **NEM-Gerüst, verblendet außerhalb VG (Molar)?** → `gleichartig/` (Verblendung außerhalb VG = Mehrleistung)

## Verblendgrenzen GKV (kritisch)

- **Oberkiefer bis Zahn 5** (Zähne 15, 14, 13, 12, 11, 21, 22, 23, 24, 25): vestibuläre Verblendung Festzuschuss-fähig
- **Unterkiefer bis Zahn 4** (Zähne 34, 33, 32, 31, 41, 42, 43, 44): vestibuläre Verblendung Festzuschuss-fähig
- **Außerhalb (OK 6-8 / UK 5-8)**: Regelversorgung = unverblendet; Verblendung wechselt zu gleichartig
