# Hinweise

- Nur PKV bzw. GKV ohne HKP/ausdrücklichem Komplett-Privatwunsch — mit HKP ist dieselbe Krone gleichartige Versorgung mit Festzuschuss 1.1 (+1.3 je vestibulärer Verblendung innerhalb VG OK 15–25/UK 34–44) → Vorlage ../gleichartig/LiSi_voll
- Entweder modular (2162 + 2612, ggf. + 2823/2832) ODER Komplettposition (2807/2810) — nie beides; 2612 nie neben 2611
- Scan-/CAD-Kette entweder in Einzelschritten (0891 je Modell + 0918 + 0917 je Krone, ggf. 0825/0827 je Segment) ODER als Sammelposition (0840 bzw. 2160) — nie additiv
- 2840 = Endkontrolle je Einheit, 2965 = Zuschlag für die Fertigung unter Mikroskop (nebeneinander nur bei Fertigung UND Endkontrolle); 0723/0724 = Farbbestimmung je Vorgang, 2963 = Ausführungsaufwand je zusätzlicher Zahnfarbe, 2951 = Charakterisierung je Einheit
- Im Leistungspreis enthalten: Verblendkeramik, Kristallisations-Ofenbedarf, Modellgips (Hartgips), Stumpf-Kunststoff/Superhartgips
- VERIFIZIEREN: (a) Modellblock gegen Laborkalkulation (0021 + 0002 + 0103 + 0104/0117), 0007 nur bei tatsächlichem Kontrollmodell; (b) Gerüstposition für ein gefrästes LiSi-Gerüst — 2162 beschreibt im Katalogtext ein Metallgerüst, 2829 die keramische Vollverblendungs-Gerüstposition; (c) ob 2823/2832 in der Hausliste neben 2162 modular kalkuliert oder darin enthalten sind
