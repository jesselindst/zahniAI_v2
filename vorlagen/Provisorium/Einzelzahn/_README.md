# Provisorium-Einzelzahn — Versorgungsform-Entscheidung

Provisorische Krone auf einem präparierten Zahn (HKP-begleitend).

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `Regelversorgung/` | HKP-begleitend, PMMA-Standard |
| `Privatleistung/` | Höherwertige Materialien (PMMA-CAD-CAM, PEEK) |

## Entscheidungsbaum

1. **PMMA-Standard im Rahmen GKV-HKP?** → `Regelversorgung/PMMA-Standard.md`
2. **PMMA-Hochwertig, CAD-CAM, PEEK?** → `Privatleistung/`
