# Implantat-Steg — Versorgungsform-Entscheidung

Stegkonstruktion zwischen Implantaten als Verankerung.

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `andersartig/` | Standardfall (4 Implantate) |
| `Privatleistung/` | PKV oder Komplett-Privatwunsch |

**Keine Regelversorgung/gleichartig** (außer in Sonderfaelle, hier nicht relevant).

Anzahl Implantate ist abrechnungsrelevant: 2-Implantate vs. 4-Implantate.
