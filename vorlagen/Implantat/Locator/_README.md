# Implantat-Locator — Versorgungsform-Entscheidung

Locator-Patrize zur Verankerung einer Deckprothese.

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `Privatleistung/` | IMMER (Standardfall, kein Sonderfall hier üblich) |

**Hinweis**: Diese Vorlagen decken die Locator-PATRIZE auf dem Implantat ab. Die Deckprothese (Matrize + Prothesenbasis) ist unter `Herausnehmbar/ImplantatProthese/` zu finden.

Anzahl Implantate ist abrechnungsrelevant: 2-Implantate vs. 4-Implantate.
