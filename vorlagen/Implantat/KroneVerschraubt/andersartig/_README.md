# Implantat-KroneVerschraubt andersartig — Material × Abutment-Auswahl

Standardfall (häufigster Fall). Reine BEB-Abrechnung. Patient bekommt Festzuschuss in Höhe Krone-/Brücke-Regelversorgung; Implantat selbst privat (GOZ + Material).

## Files

| File | Material | Abutment-Typ |
|---|---|---|
| `Zirkon_Tibase.md` | Vollkeramik Zirkon | Vorgefertigte Titan-Klebebasis (Tibase) + Zirkon-Mesostruktur, verklebt |
| `Zirkon_individuell-Titan.md` | Vollkeramik Zirkon | Individuell gefräst aus Titan |
| `LiSi_Tibase.md` | Lithiumdisilikat | Tibase + LiSi-Mesostruktur |
| `VMK_individuell-Titan.md` | Metallkeramik | Individuell gefräst aus Titan |

## Wahl-Kriterien

- **Frontzahnbereich, höchste Ästhetik gewünscht**: Zirkon_individuell-Zirkon (siehe `Privatleistung/`)
- **Frontzahn-Standard**: Zirkon_Tibase (gute Ästhetik, kostengünstiger)
- **Frontzahn-Klassisch**: LiSi_Tibase
- **Seitenzahn (hohe Stabilität)**: Zirkon_individuell-Titan oder VMK_individuell-Titan
- **Seitenzahn-Standard**: Zirkon_Tibase
