# Totalprothese Regelversorgung — OK vs. UK

PMMA-Kalt + Standard-Kunststoffzähne nach Befund 5.x.

## Files

| File | Kiefer | Besonderheit |
|---|---|---|
| `PMMA-kalt_Standard_OK.md` | Oberkiefer | Mit Palatinalplatte (komplette Gaumenbedeckung) |
| `PMMA-kalt_Standard_UK.md` | Unterkiefer | Ohne Palatinalplatte (anatomisch nicht möglich) |

## OK + UK kombiniert

Wenn der Patient sowohl OK als auch UK Totalprothese benötigt: beide Vorlagen kombinieren. Modelle, Bissregistrierung etc. einmal abrechnen, NICHT verdoppeln.

## Material-Wahl

Die Vorlage `PMMA-kalt_Standard_*.md` ist BEL-Standard. Höherwertige Materialien (PMMA-Heiß, Premium-Zähne) wandern in `gleichartig/`.
