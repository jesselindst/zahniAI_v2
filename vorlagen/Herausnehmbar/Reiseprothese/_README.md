# Reiseprothese — Versorgungsform-Entscheidung

Zweite Prothese als Ersatz/Reserve für Reisen oder als Backup.

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `Privatleistung/` | IMMER |

**Klassifizierung**: Reiseprothese ist KEINE GKV-Leistung (es gibt nur einen Festzuschuss pro Versorgungszeitraum). Komplett-Privat über GOZ + BEB.
