# ImplantatProthese — Versorgungsform-Entscheidung

Deckprothese auf 2-4 Implantaten mit Locator/Steg/Teleskop-Verankerung.

## Versorgungsform-Tabelle

| Versorgungsform | Wann? |
|---|---|
| `Sonderfaelle/` | Ausnahmeindikationen §28 Abs.2 SGB V |
| `andersartig/` | Standardfall (Implantat-Prothese statt Modellguss/CoverDenture) |
| `Privatleistung/` | PKV oder Komplett-Privatwunsch |

**Keine Regelversorgung/gleichartig** (außer in Sonderfaelle).

## Klassifizierungs-Regel

**Standardfall**:
- Implantat-Prothese als Ersatz für Cover Denture/Modellguss → ZE-Typ-Wechsel = **andersartig**
- Festzuschuss in Höhe Cover Denture (Befund 4.x) oder Modellguss (Befund 3.x), je nach hypothetischer Regelversorgung
- Implantatchirurgie selbst privat (GOZ)

**Sonderfaelle (5 Ausnahmeindikationen §28 Abs.2 SGB V)**:
1. Größere Kiefer-/Gesichtsdefekte (Tumor-OP, Trauma)
2. Operationen nach großen Zysten (follikuläre, Keratozysten)
3. Operationen nach Osteopathien
4. Angeborene Kieferdefekte (LKG-Spalte, ektodermale Dysplasie)
5. Unfälle

→ Implantat als Sachleistung. Suprakonstruktion nach ZE-RL §36a/b regelhaft oder gleichartig.

**Zusätzliche Bedingung Sonderfall**: konventioneller ZE NICHT möglich.

## Entscheidungsbaum

1. **PKV oder Komplett-Privatwunsch?** → `Privatleistung/`
2. **Liegt eine der 5 Ausnahmeindikationen vor UND konventioneller ZE nicht möglich?** → `Sonderfaelle/`
3. **Standardfall** → `andersartig/`
